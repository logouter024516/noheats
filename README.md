# HeatPizza (열을피자)

KAIST IP-CEO workshop project. HeatPizza is mobility decision support for hot conditions: it helps a person decide **what to do, when to leave, and how to travel**. It is not a weather map and not a service that merely finds shaded streets.

The first deliverable is a real web MVP, landing page, and HTML presentation within 24 hours. The implementation home is the existing Expo Router app in `apps/app`.
