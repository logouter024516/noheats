# Expo 57 application notes

This is the HeatPizza client application. Follow the repository-level `../../AGENTS.md` and product documents before feature work.

Read the exact versioned documentation at https://docs.expo.dev/versions/v57.0.0/ before writing Expo-specific code. Preserve Expo Router and TypeScript conventions already present in the starter unless a product requirement calls for a change.

Do not run `scripts/reset-project.js`: this app is the approved starting point for the HeatPizza MVP. Build the responsive web experience here first; native polish is not a P0 dependency.
